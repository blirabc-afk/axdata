🔐 비밀번호 변경

비밀번호 변경은 GCP Cloud Shell에서 다음 명령어로 진행하세요: 
gcloud run services update axdata-uploader \
  --region asia-northeast3 \
  --update-env-vars ADMIN_PASSWORD=새비밀번호
